# 📊 Amazon Product Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze Amazon product data and provide insights into products, categories, pricing, ratings, reviews, and discounts.

---

## 🎯 Project Overview

This project focuses on analyzing Amazon product data using Power BI.

The dashboard provides a clear overview of product performance and helps identify trends across different product categories.

---

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Data Analysis

---

## 📌 Key Performance Indicators

| KPI | Value |
|---|---:|

## 📈 Dashboard Features

- 🔝 Top 5 Products by Reviews
- 📦 Product Count by Category
- 💰 Discount Distribution by Category
- ⭐ Rating Distribution
- 📊 Average Rating by Category
- 💵 Average Price by Category
- 🔎 Category Filter
- 🔎 Product Name Filter
- ⭐ Rating Filter
- 💡 Key Business Insights

---

## 💡 Key Insights

- 🏠 **Home & Kitchen** has the highest product count.
- ⭐ **Office Products** has the highest average rating.
- 🔌 **AmazonBasics HDMI Cable** has the highest number of reviews.
