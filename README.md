# Amazon Product Analytics Dashboard

An interactive Power BI dashboard designed to analyze Amazon product performance, pricing, ratings, reviews, and category-level insights.

## 🛠️ Tools Used

- Power BI
- Data Analysis
- Data Visualization

## 📊 Key KPIs

- Total Products: 1.35K
- Total Categories: 10
- Total Reviews: 26.77M
- Average Rating: 4.1

## 📈 Dashboard Features

- Top 5 Products by Reviews
- Product Count by Category
- Discount Distribution by Category
- Rating Distribution
- Average Rating by Category
- Average Price by Category
- Category and Product Filters
- Key Business Insights

## 💡 Key Insights

- Home & Kitchen has the highest product count.
- Office Products has the highest average rating.
- AmazonBasics HDMI Cable has the highest number of reviews.
